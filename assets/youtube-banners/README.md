## 규격

- 크기 **2048 × 1152** (유튜브 권장 업로드 크기)
- 글자와 로고는 모두 중앙 **1235 × 338 안전영역** 안에 배치
  → TV·PC·모바일 어디서 잘려도 내용이 보입니다
- 장당 약 300KB (유튜브 제한 6MB)

## 올리는 법

```
studio.youtube.com
  → (해당 채널로 계정 전환)
  → 왼쪽 「맞춤설정」 → 상단 「브랜딩」 탭
  → 「배너 이미지」 → 업로드 → 자르기 확인 → 「게시」
```
