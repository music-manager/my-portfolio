# 포트폴리오 첫 화면 캡처

여기에 사이트 첫 화면 캡처 이미지를 넣고,
`src/data/site.ts` 의 `portfolio.items[].thumbnail` 에 경로를 적으세요.

    thumbnail: "/portfolio/petdamda.png",

## 권장 사양

- 가로:세로 = **16:9** (예: 1600 × 900)
- PC 화면 기준 첫 화면(스크롤 전) 캡처
- 형식: PNG 또는 JPG
- 파일명은 영문 소문자로 (예: `petdamda.png`, `esedy.png`)

`thumbnail` 을 빈 값(`""`)으로 두면 이미지 없이 글자만 있는 카드로 표시됩니다.
